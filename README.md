🏠 Smart Home IoT Project

A Smart Home IoT Automation System developed as part of the CodeAlpha Internship project.
The project combines a physical Arduino-based hardware implementation with an ESP32-based simulation using Wokwi.

---

📂 Project Structure

- "Hardware/"
  Contains the Arduino source code used for the physical Smart Home hardware implementation.

- "Hardware_Results/"
  Contains documentation and screenshots of the hardware testing, including the physical circuit, Serial Monitor results, and Bluetooth terminal communication.

- "Simulation/"
  Contains the ESP32 source code used for the virtual Smart Home simulation on Wokwi.

- "Simulation_Results/"
  Contains screenshots and documentation of the simulation tests and their results.

- "Report/"
  Contains the complete project research and technical report in PDF format.

---

🛠️ Technologies & Tools Used

- Microcontroller: Arduino
- Simulation Microcontroller: ESP32
- Programming Language: C/C++
- Sensors & Components: Ultrasonic Sensor, Temperature & Humidity Sensor, Gas Sensor, PIR Motion Sensor, IR Sensor, LED, Buzzer, and HC-05 Bluetooth Module
- Simulation Platform: Wokwi IoT Simulator
- Development Environment: Arduino IDE
- Documentation: Markdown & PDF

---

⚙️ Project Features

The Smart Home system monitors different environmental and motion conditions using multiple sensors.

The system includes:

- Distance detection using an Ultrasonic Sensor.
- Temperature and humidity monitoring.
- Gas detection and warning.
- Motion detection using a PIR sensor.
- IR-based detection.
- Visual indication using LEDs.
- Audible warning using a Buzzer.
- Bluetooth communication using the HC-05 module.

The hardware implementation and the virtual simulation are tested separately to verify the system behavior.

---

🧪 Testing & Results

Hardware Testing

The physical Arduino-based system was tested under different conditions, including:

- Normal operating conditions.
- Sensor-triggered conditions such as gas detection and increased temperature.
- Verification of the corresponding LED and Buzzer responses.
- Bluetooth communication testing using the HC-05 module.

The test results and visual documentation are available in the "Hardware_Results/" folder.

Simulation Testing

The Smart Home system was also implemented using an ESP32 in the Wokwi simulation environment.

The simulation results and screenshots are available in the "Simulation_Results/" folder.
